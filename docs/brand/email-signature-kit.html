Einbau

    

      Auf Signatur kopieren klicken, dann im Mail-Client einfügen. Der Button legt
      formatiertes HTML und reinen Text in die Zwischenablage — der Client nimmt sich,
      was er versteht.
    


    
Apple Mail (macOS) — der Weg, der funktioniert

    
    
      
  1. Diese Seite in Safari öffnen. Safari übergibt formatiertes HTML sauberer an Mail als Chrome.
    2. 
      
  2. Mail → Einstellungen → Signaturen. Links das Konto wählen, nicht „Alle Signaturen".
    3. 
      
  3. + drücken. Dann Häkchen „Immer meine Standardschriftart verwenden" entfernen — sonst wirft Mail Farben und die Fairway-Kante weg.
    4. 
      
  4. Rechts ⌘A, löschen, einfügen (⌘V).
    5. 
      
  5. Verliert das Einfügen die Formatierung: Signatur im Browser markieren und ins Feld ziehen. Drag-and-drop umgeht Mails Zwischenablage-Filter.
    6. 
    


    
Outlook (Web / Microsoft 365) und Gmail

    
    
      
  1. Outlook: Einstellungen → E-Mail → Verfassen und Antworten → Signatur. Web-Outlook übernimmt HTML zuverlässiger als die Desktop-App.
    2. 
      
  2. Gmail: Einstellungen → Allgemein → Signatur → Neu erstellen.
    3. 
    

  


  

  

    

    
iPhone und iPad

    

      Das iOS-Signaturfeld speichert kein HTML, sondern formatierten Text. Farben und Fettung
      überstehen das Einfügen — Hyperlinks nicht. Beim Senden verlinkt iOS
      anschließend automatisch alles neu, was wie eine Adresse aussieht, in seiner eigenen
      Systemfarbe. Ein beschrifteter Link wie „Mitglied werden" bleibt deshalb als toter Text
      zurück: es gibt nichts zu erkennen.
    

    

      Die Fassung unten löst das, indem jede Adresse ausgeschrieben ist. Kein
      <a>-Tag, keine Beschriftung — die automatische Erkennung macht daraus
      auf jedem Gerät wieder klickbare Links.

Warum es so aussieht


    

      

        
          
EntscheidungGrundMesswert

        
        
          

            Links in Fairway #1b6640
            Der Markenakzent trägt kleinen Text auf Weiß, ohne dass er nachgedunkelt werden muss.
            6,95:1 — AA
          

          

            Preis in Gold-deep #7a5a0e
            Gold nur an der einen Stelle, die überzeugen soll — dem Preis. Genau die sparsame Verwendung, die der Token-Kommentar vorsieht.
            6,37:1 — AA
          

          

            Gold #d4a12e kommt als Schrift nicht vor
            Auf Weiß gemessen fällt es durch. Der Token-Kommentar „NOT a fill" ist damit auch rechnerisch belegt, nicht nur Konvention.
            2,35:1 — fällt durch
          

          

            Clubname in Serif
            Playfair Display lädt im Postfach nicht. Anders als bei einer Grotesk gibt es hier einen guten Ersatz: Georgia ist auf macOS und Windows vorinstalliert und trägt denselben Ton.
            —
          

          

            Kein Logo-Bild
            Gmail und Outlook blockieren externe Bilder per Default. Ein gehostetes Logo erscheint dann als kaputtes Platzhalter-Icon.
            —
          

          

            Tabellen statt div/Flexbox
            Outlook rendert mit der Word-Engine. Flexbox, Grid und margin auf Blockelementen fallen dort still aus.
            —
          

          

            Telefon-Link nicht eingefärbt
            Bleibt klickbar, sieht aber nicht nach Link aus — sonst hat die Kontaktzeile drei bunte Elemente.
            —
          

        
      

    


    

      Dark-Mode-Warnung. Schalte oben auf „Dunkel". Ink #0a0a0a
      und das Fairway-Grün verlieren dort deutlich an Kontrast. Apple Mail und Gmail hellen
      dunkle Textfarben meist automatisch auf, Outlook nicht zuverlässig. Deshalb ist keine
      Fläche eingefärbt: eine Signatur ohne eigenen Hintergrund überlebt jede Client-Invertierung.
